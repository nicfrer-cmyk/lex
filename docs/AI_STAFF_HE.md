**הצ׳אט הצף הוא מנהל/ת המשרד.** הוא עונה מהנתונים, ומאציל לצוות:
"תכין לי פוסט על עיקול משכורת" → הוא מעביר לקריאייטיב, והתוצר מופיע ב"תוצרים".

## מתזמן (פעם אחת, 5 דקות)

```bash
bash scripts/setup-cron.sh
```
הסקריפט מייצר `CRON_SECRET`, שומר אותו ב-Supabase ומדפיס SQL להדבקה ב-SQL Editor.
ה-SQL יוצר job של pg_cron שקורא ל-`ai-cron` כל 5 דקות עם המשימות
`reap, routines, drain, learn`. `routines` הוא מה שמכניס את שגרות הצוות לתור.

בדיקה: אחרי 10 דקות, בלשונית "הצוות" הכותרת תציג "המתזמן פעיל".

## איך תוצר עובר מהצוות לעולם

```
סוכן → create_work_item (טיוטה) → "תוצרים" → אתה: ערוך/אשר → העתק → פרסם בערוץ → "סמן כפורסם"
```
הודעות ללקוחות ולידים עוברות ב"אישורים" (כמו קודם), ונשלחות רק דרך ai-comms אחרי אישור.

## עלויות
מודל ברירת מחדל: Haiku 4.5 לסוכנים תפעוליים, Sonnet 4.6 לכותבים. צוות מלא שעובד כל יום:
$20–60 לחודש. התקציב (יומי/חודשי) ב"הגדרות וחיבורים"; חריגה עוצרת את הצוות או מורידה מודל.
